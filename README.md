# tool

자주 쓰는 간단한 도구 모음. 새 작업을 시작하기 전에 여기 이미 있는 도구가 있는지 먼저 확인한다.

각 도구의 자세한 설명·옵션·의존성은 `./<도구> -h`로 확인한다.

## 도구 목록

| 도구 | 설명 | 예 |
| --- | --- | --- |
| [`pptx2pdf.sh`](pptx2pdf.sh) | PowerPoint(.pptx)를 깨짐 없이 PDF로 변환 (내장 글꼴 복원, 치장용 배경 제거, 이미지 다운샘플) | `./pptx2pdf.sh slides.pptx` |

## 도구 추가 규칙

- 스크립트는 저장소 루트에 두고 실행 권한(`chmod +x`)을 준다.
- 자세한 설명은 스크립트 상단 주석 한 곳에만 쓰고 (설명·사용법·옵션·의존성), `-h`가 그 주석을 출력하도록 한다.
- 스크립트의 출력·주석은 영어(ASCII)로 쓴다.
- 추가하면 위 **도구 목록** 표에 한 줄을 더한다. 설명이 아주 긴 도구만 `docs/<도구>.md`로 분리한다.
